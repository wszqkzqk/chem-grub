# Security policy

The installer changes GRUB configuration and should only be run after reviewing
its source. Use `--dry-run` to inspect its plan, and keep the backups it creates.
Do not run an installer downloaded from an unverified fork or attachment.

Report suspected vulnerabilities through GitHub Issues at
https://github.com/wszqkzqk/chem-grub/issues. Do not include passwords, private
keys, recovery codes, or other secrets in a report. Ask for a private contact
route if a report needs sensitive reproduction details.

The latest build on the main branch is supported with fixes.
