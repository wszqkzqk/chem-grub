# Changelog

All notable changes to Chemistry GRUB will be documented here. The project
follows semantic versioning.

## [Unreleased]

### Changed

- Refined the mascot's eyewear into one-piece laboratory safety goggles with
  side shields and a head strap.
- Aligned the goggle bridge, eye midpoint, and mouth on the mascot's vertical
  centerline.
- Moved the notebook's NOTES label into the right page's top margin.

## [1.0.0] - 2026-10-19

### Added

- Original Chem Grub scientist artwork and midnight laboratory background.
- GRUB2 theme with responsive menu, selection, scrollbar, timeout, and terminal
  resources.
- CJK-capable PF2 fonts with 44,810 glyphs at each included size.
- Native GRUB localization for the title, key help, and timeout message.
- Nested-menu layouts for Arch advanced options and grub-btrfs snapshots.
- Installation script with configuration backups and dry-run support.
- Arch Linux `PKGBUILD` and an Arch Linux package CI job.
- Reproducible build, preview generation, CI, and tag-based release packaging.
